# 관계를 이어가는 캐릭터 경험

2026-10-11 · 관계 기능 구현 및 로컬 검증 기록. 기존 설계 문서의 당시 상태와 구분한다.

## 제품 동작

- 미로(`reality`)의 새 세션은 관계 판단 정책 `agency:v1`을 기본으로 사용한다. 기존 활성 미로 세션은 다음 대화/백그라운드 평가 때 정책 전환을 한 번 기록한다. 대화, 기억, 관계 수치와 세계 상태는 보존한다. 일반 `chat`은 기존 정책을 유지한다.
- 회수한 기억의 원문 메시지를 같은 세션의 실제 관측 근거로 전달한다. 약속, 취소, 서운함과 사과를 다음 선택에 연결하고, 고백/거절/이별 등 실제 사건을 단계 판단에 반영한다. 관계 수치가 높다는 이유만으로 연애나 동의를 확정하지 않는다.
- 식사 시간, 창가 풍경과 침묵은 재검토 계기다. 그것만으로 먼저 연락하지 않는다. 실제 교환, 유효한 약속, 함께 남긴 문제나 공유할 수 있는 자신의 사건이 필요하며 기다리기도 선택할 수 있다.
- 작성자가 설정한 연락 수단도 지킨다. 휴대폰을 쓰지 않는 인물의 직접 대화 약속을 문자 약속으로 바꾸지 않는다. 가능한 예외는 원문/관측 근거가 필요하다.
- 대화 표현에는 이전에 완료한 자신의 행동과 자신의 속마음을 보존한다. 다른 인물의 비공개 행동/내면은 전달하지 않는다. 행동 기록은 유저가 말했다는 근거로 사용하지 않는다.

## 유저가 요청한 거리

`roleplay_sessions.contact_boundary`는 관계 점수와 별개인 전달 제한이다. 인증된 요청을 확인하고 모델 호출·토큰 예약 전에 저장하므로 생성 실패나 잔액 부족으로 지워지지 않는다.

- `open`: 먼저 연락할 수 있음. 별도의 성격/상황/설정 검증은 계속 적용한다.
- `paused`: 기한까지 선연락 차단. “오늘은 혼자 있고 싶어”는 유저 시간대의 다음 자정까지, 기한 없는 혼자만의 시간 요청은 기본 24시간이다.
- `blocked`: “먼저 연락하지 마”처럼 기한 없는 중단은 명시적인 재허용 전까지 차단한다.
- 뒤에 오는 단순 중단 문장은 앞 문장의 명시적인 잠시 쉬기 기한을 따른다. “오늘은 혼자 있고 싶어. 먼저 연락하지 마.”는 오늘까지다.
- 유저가 새 대화를 보내면 답할 수 있다. 그것만으로 선연락을 다시 허용하지 않는다. 공간 요청을 적대/이별로 해석하지 않도록 같은 지시를 판단과 표현에 전달한다.

파서는 직접적인 한국어/영어/일본어/중국어 표현을 보수적으로 인식한다. 인용·전언·가정·주요 부정 표현을 제외하지만 모든 우회 표현이나 글자로 쓴 기간을 이해하는 것은 아니다. 일반 대화 의미 판단을 완전히 대체하지 않는다.

선연락 평가 시작과 저장 직전, 알림 전달 직전에 최신 제한을 다시 확인한다. 기존 대기 알림은 취소하고 기한 종료 후 되살리지 않는다. 발송은 세션 공유 잠금 안에서 최신 요청·발송 작업·목표 취소·`pushEnabled`를 재검사한다. 중단 저장 뒤에 새로운 외부 발송을 시작할 수 없지만 이미 시작한 외부 전달은 회수할 수 없다. 기존 `quietHoursStart/End` 설정은 이번 변경에서 연결하지 않았다.

## 적용 및 복구

1. 운영 코드 배포 전에 `packages/db/migrations/20261011220000_contact_boundary.sql`을 적용한다. 추가 컬럼만 만드는 멱등 변경이다.
2. `MIRO_CHARACTER_AGENCY_MODE`가 비어 있으면 `live`가 기본이다. 기존 명시적인 `off`는 계속 중단 스위치로 동작하므로 배포 환경에 이전 값이 있는지 확인한다. `MIRO_AGENCY_DEFAULT_POLICY=legacy:v1`은 신규/기존 세션의 자동 채택을 중단한다.
3. `MIRO_CHARACTER_AGENCY_MODE=off`로 판단 경로를 중단해도 저장된 연락 제한과 발송 검사는 유지된다. 기존 `agency:v1` 기록은 삭제하지 않는다.
4. 컴파일된 인물 설정이 준비되기 전 대화는 기존 검증 경로를 사용하며 새 자율 연락은 보류한다.

## 확인한 범위

- 관련 도메인/엔진/DB 통합 검사 185개 통과. 루트와 웹 타입 검사 통과.
- 공개된 차도겸·구만석·서이안의 작성 설정을 복사한 격리된 로컬 대화에서 실제 모델로 26턴을 실행했다. 실제 앱 대화/저장/백그라운드 평가 경로를 사용했으며 실제 유저 대화와 기기 알림은 사용하지 않았다.
- 세 인물 모두 연락 약속 생성 → 취소를 기록했다. 잠시 쉬기 이후 6번의 백그라운드 평가는 `user_boundary`로 막혔고 추가 모델 호출이 0회였다. 평범한 대화는 제한을 해제하지 않았고 명시적 재허용은 해제했다.
- 약속 시각을 넘긴 평가에서 차도겸·서이안은 약속에 맞는 메시지를 저장했다. 구만석의 전화 미사용 설정과 문자 발송 충돌을 발견해 판단 지시를 보완했고, 재실행에서는 직접 말로 묻겠다고 답하고 백그라운드 문자를 보내지 않았다.
- 이전 동작을 되풀이하는 표현 문제를 발견해 자신의 행동 이력을 표현 맥락에 보존하도록 수정했다. 자동 검사와 후속 실제 대화로 전달 경로를 확인했다.

이 평가는 테스트에서 활동 시간을 열어두고 시간을 앞당겨 백그라운드 평가를 호출했다. 운영 스케줄러, 실제 푸시 전달, 수개월의 관계 변화와 모든 캐릭터의 문체를 검증한 결과는 아니다. 의미 판단·약속 이행의 선택·문체 품질은 모델 결과에 따라 달라질 수 있다.
