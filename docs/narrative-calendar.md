# 채팅방의 세계관 날짜

채팅방 헤더의 문자 아이콘 오른쪽에 있는 달력 버튼을 누르면 세계관 날짜를 고를 수 있다. 현재 날짜는 버튼의 도움말과 접근성 이름으로 확인할 수 있다. 기존 대화에는 날짜를 임의로 붙이지 않는다. 선택창의 초기값은 사용자 시간대의 오늘이며, 직접 고르거나 하루·일주일·30일 뒤로 이동할 수 있다.

저장하면 대화에 날짜 구분선을 추가한다. `2026-10-11`에서 `2026-10-18`로 옮기면 `7일 후 · 2026-10-18`이다. 선택값은 새로고침 뒤에도 유지된다. 답변 생성 중에는 변경할 수 없다.

## 이야기와 실제 연락

- 선택한 날짜는 직접 만나는 장면 채팅에만 적용한다. 사용자가 다시 바꾸기 전까지 유지한다.
- 변경 직후의 다음 장면 응답에서 지난 시간을 캐릭터 말투·행동에 자연스럽게 반영하도록 계획기와 대사 생성기에 전달한다. 짧은 입력도 이때는 계획을 생략하지 않는다.
- 날짜 이동만으로 관계 점수·단계·동의·약속 이행이 바뀌지 않는다. 그 사이에 나누지 않은 경험을 만들어내지 않도록 지시한다.
- 과거 날짜를 고를 수 있지만, 기존 대화나 이미 저장한 관계·사건을 되돌리지는 않는다.
- 실제 문자·통화·푸시 예약과 연락 중단 요청은 현실 시간을 따른다. 선택한 장면의 “내일”을 실제 알림 일정으로 저장하지 않는다.
- 서사 약속은 서사 날짜에, 현실 연락 약속은 현실 시각에 맞춰 이행 가능 여부를 검사한다. 백그라운드 알림으로 서사 약속을 완료할 수 없다.

## 저장 및 충돌

`world_states.narrative_calendar`에 날짜·변경 전 날짜·변경 시점의 턴을 저장한다. 서버는 소유자, 대화/캐릭터/계정의 사용 가능 상태, 유효한 날짜, 생성 중인 요청을 검사한다. 대화 요청과 같은 잠금을 사용하고, 세계 상태 버전을 올려 이전 상태로 생성한 결과의 덮어쓰기를 막는다.

클라이언트가 본 날짜와 현재 날짜가 다르면 충돌을 알린다. 동일 날짜 재요청은 구분선을 중복 삽입하지 않는다. 같은 턴에서 여러 차례 변경한 경우 다음 응답에는 첫 변경 전 날짜부터의 차이를 전달한다. 상태 변경 원장에는 사용자에 의한 서사 시간 변경으로 기록한다.

## 배포 및 검증

코드 배포 전에 `20261011230000_narrative_calendar.sql`의 추가 컬럼을 먼저 적용해야 한다. 기존 관계 기능 수정과 함께 운영에 올릴 때는 연락 경계 추가 마이그레이션도 포함한다.

확인 범위: 날짜 유효성/윤년/시간대 차이, 인증/제한/삭제, 재요청과 동시 변경, 생성 중 변경 및 이전 세계 버전 커밋 거부, 계획기·대사 생성기의 날짜 전달, 현실 연락과 서사 약속의 분리. 모바일 390px·320px 및 데스크톱에서 선택/빠른 이동/새로고침 유지와 가로 넘침을 검사했다. 실제 공급자와 서이안 2턴으로 우유 취향을 전달하고 일주일 뒤 다시 대화하는 흐름도 확인했다. 한 캐릭터의 실제 생성 확인으로 모든 응답 품질을 보장하지 않는다.
