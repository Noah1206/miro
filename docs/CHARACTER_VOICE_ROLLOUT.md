# 캐릭터 음성 기능 보류와 재개

현재 출시에서는 캐릭터 TTS를 보류하고 기존 리얼리티 문자·관계·기억·이미지 기능을 유지한다. 가중치나 녹음은 이 변경에 포함하지 않는다.

## 현재 기본값

- `MIRO_FEATURE_CHARACTER_VOICE=0`: 음성 모드·잔여량·분량 구매·말로 쓰기와 캐릭터 제작의 목소리 선택을 숨긴다. 이전 기기에 저장된 음성 ON 값만으로는 켜지지 않는다.
- 합성 API는 기능 OFF일 때404를 반환한다. 음성 체험 지급·분량 구매·워커 신규 실행도 차단한다. 기존 대기 작업은 취소·분량 반환할 수 있다.
- 문자방의 전화 버튼은 제거했다. 캐릭터챗과 문자방 입력 글자는 테마별 placeholder와 같은 크기다.
- `MIRO_SCENE_IMAGES_ENABLED=0`: 운영 상황 이미지 생성은 별도 검증 후 켠다. 기존 등록 에셋을 상황 메타데이터로 찾는 경로와 일반/언베일 공급자 분리 코드를 포함한다.

## 나중에 음성을 다시 열 때

1. 실제 모델의 대사 완주·음색·연기·지연·정상 출력 원가를 검증한다. WAV 형식/길이/무음 검사는 대사 내용의 완주 검사와 다르다.
2. 기존 큐 마이그레이션 이후 `20261026094906_speech_credit_accounts.sql`을 적용한다. 이 커밋을 푸시하는 것만으로 운영 DB가 바뀌지는 않는다.
3. 웹과 별도 워커의 모델/참조 버전·요청별/사용자별/전역 예약 한도·공급자 키를 일치시킨다. 앱의 예약 한도는 공급자 GPU 유휴 요금의 하드 상한이 아니다.
4. 실측한 원가를 바탕으로 `MIRO_SPEECH_PRODUCTS`와 체험 정책을 설정한다. 기본 상품은 빈 배열이다. 음성 분량 구매는 구매 충전금만 사용한다.
5. `MIRO_FEATURE_CHARACTER_VOICE=1`, `MIRO_TTS_QUEUE_ENABLED=1`, `MIRO_SPEECH_CREDITS_ENABLED=1`을 함께 켜고, 워커에만 `MIRO_SPEECH_ALLOW_PROVIDER=1`을 설정한다.
6. 실제 휴대폰에서 생성·재생·취소·재접속과 실패 정산을 검증한 후 제한적으로 연다.

보통/길게는 같은 모델 품질의 분량 구분이다. 각각 최대40자/10초와80자/20초를 허용한다. 최대 분량 예약 후 서버에서 검사한 WAV 길이를1초 단위로 올림해 정산한다. 실패·불명확 응답은 사용자 분량을 반환하고, 결과 불명확 시 신규 합성을 중단한다. 자동 유료 재시도는 없다.

완료 음성 캐시는24시간 재사용하며 다시 듣기는 추가 차감하지 않는다. 무료 캐시가 만료되는 순간에도 새 유료 생성으로 자동 전환하지 않는다. 이미 공급자에 전송한 작업의 즉시 계산 취소는 보장하지 않는다.

## 검증 범위

로컬 전용 DB와 가짜 공급자로 동시 요청·중복 구매·분량 반환·대기 취소·불명확 결과 격리·캐시 만료·기능 OFF 경로를 검사한다. 이 검증은 실제 학습 모델의 음질이나 실제 결제를 입증하지 않는다.

### 푸시 전 확인

음성 보류·분량 정산·큐·캐시·에셋 경계·선택 재생·합성 API 집중 검사43개와 타입 검사, 웹/관리자 빌드를 확인했다. 전체 검사에서 기존 무료 제공량 정책 및 샘플/스토리 fixture 등을 전제로 한 실패60개는 수정 전 기준 코드에서도 동일하게 재현했다. 이 기존 실패는 별도 정리가 필요하며, 전체 테스트가 통과한 상태라는 의미는 아니다. 운영 DB 적용이나 배포를 이 변경만으로 실행하지 않는다.
