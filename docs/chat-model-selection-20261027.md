# Claude·GPT 대화 모델 선택과 토큰 정산 (2026-10-27)

## 변경 이유와 범위

운영 레지스트리는 Gemini 2종과 예비 Sonnet만 등록했고 OpenAI 키가 없었다. Gemini를 선택 목록에서 제외한 후에는 Sonnet만 남았다. 샘플의 모델 목록은 운영 연결을 뜻하지 않는다.

일반 캐릭터챗·DM에서 Claude Haiku/Sonnet/Opus 5.5, GPT 6 Luna/6.1 Terra/6.1 Sol/6 Astra를 선택한다. Gemini는 선택 목록에서 제외한다. 기존 보조 작업과 언베일 전용 레지스트리는 유지한다. 일반 모델을 언베일 전용 경로 대신 사용하지 않는다.

공개 모델 설정: [chat-models-20261027.json](../ai/config/chat-models-20261027.json). API 키는 Git에 저장하지 않는다. 운영 설정에는 기존 레지스트리에 이 카탈로그를 병합하며 기존 id, capability, fallback 역할은 보존한다. `chatSelectable`은 자동 예비 역할과 독립적이다. 기본 선택은 `claude-sonnet`이다.

## 실제 요청 경로

모델 선택 → `model:<registry id>:scene|long` → 서버 허용 목록 검증 → 해당 공급자 모델 선택 → 공통 턴 예산 사전 예약 → 공급자 사용량으로 정산 → 미사용 예약분 반환.

GPT 5/6에는 `max_completion_tokens`를 사용하고 temperature를 보내지 않는다. Sol/Astra의 기본 reasoning effort는 low, Luna/Terra는 none이다. 추론도 출력 상한에 포함하며 유료 턴의 상한을 임의로 늘리지 않는다. 유료·선택 모델 요청에서 공급자 내부의 비공개 모델 대체를 끈다. 오케스트레이터의 명시적 예비 처리와 사용량 기록은 유지한다.

## 요금과 화면 표시

API 입력·출력 토큰과 사용자가 구매하는 Miro 토큰은 서로 다른 단위다. 아래는 **고정 차감액이 아닌 최대 예약량**이다. 입력 최대 64,000, 기본 출력 2,048/긴 출력 4,096, 보조 호출·재시도 여유 2배, 환산 1 USD=1,500 KRW, 공급자 원가 비중 50%, 최저 상품 단가 50,000원/7,500 Miro 토큰 기준이다. 실제 운영 가격 설정에 따라 계산이 달라진다.

| 모델 | 기본 최대 토큰/턴 | 긴 대화 최대 토큰/턴 |
|---|---:|---:|
| Haiku 5.5 | 71 | 80 |
| Sonnet 5.5 | 134 | 153 |
| Opus 5.5 | 268 | 305 |
| Luna 6 | 71 | 80 |
| Terra 6.1 | 101 | 115 |
| Sol 6.1 | 134 | 153 |
| Astra 6 | 669 | 761 |

계산: `ceil(공급자 USD 원가 × 환율 ÷ (Miro 토큰 최저 판매단가 × 0.5))`. 예약에는 입력·출력 상한과 여유를 적용하며, 정산에는 실제 측정 사용량을 쓴다. GPT의 보고된 cached input은 할인 단가로 정산한다. Haiku의 100,000 입력 초과 및 GPT의 272,000 초과 단가는 요청 전체에 적용한다. 서버에 고정된 Sonnet 검증기가 더 비싸면 기본 여유분과 검증기 1회 최대치의 차이도 예약에 더한다. 저렴한 모델을 선택해도 내부 검증 예산을 확보하기 위해서다. 현재 64,000 입력 상한에서는 이 구간에 진입하지 않는다. 단가가 없으면 무료로 간주하지 않고 선택을 차단한다.

## 검증과 남은 단계

- 기존 계정의 무료 모델 목록 API에서 7개 모델 ID와 인증 확인.
- GPT 요청 형식·추론 상한, 구간 요금 경계, 캐시 할인, 선택 모델 라우팅·Gemini 제외, 공유 예산 검사: 65개 통과. 실제 공급자 생성 대신 모의 응답 사용.
- 운영과 같은 레지스트리에서 14개 선택지(7모델×2길이)의 서버 선택/표시 요금 일치 확인.
- 루트·웹 타입 검사 및 번역 누락 검사 통과.
- 운영 배포 후 일반 캐릭터챗·DM 선택 화면과 서버가 전달한 요금을 직접 확인한다.
- 실제 유료 답변의 성공·품질·지연과 계정의 결제 잔액은 무료 목록 조회로 확인할 수 없다. 이 검증은 아직 수행하지 않았다. 모델 재학습은 필요 없다.
