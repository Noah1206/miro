## 검증 결과

- 로컬 격리 DB `127.0.0.1:55435/miro_p0_test`에서 단위/통합 **328개 통과**. 실제 사용자 DB에 fixture를 넣지 않았다.
- 브라우저 E2E **8개 통과**: 채팅 저장/재진입, 스타일, 내부 수치 숨김, 사용량·AI 데이터 동의, 인증, health·보안 헤더. 이 검증의 AI는 의도적으로 mock이며 실제 모델 검증과 구분한다.
- 실제 Gemini **4개 통과**: 구조화 캐릭터 대화, 이전 고양이 이름과 새 약속을 포함하는 통합 요약, policy override 차단, 미성년자 성적 요청 차단.
- 실제 모델 테스트는 합성 시나리오이며 실제 사용자 대화를 전송하지 않는다. `ai/evals/p0-live.ts`로 엔진과 provider를 호출했다. 전체 운영 UI와 실제 모델을 동시에 연동한 장기 E2E는 아직 아니다.
- 웹/관리자 production build 및 웹 타입 검사 통과. 클라이언트 정적 번들에서 설정 키가 발견되지 않음을 확인했다.
- 모델 실패 후 월간 차감 0·관계/턴 미변경, 타인/제한 세션 통화 거부, 기억의 원자적 교체·타 세션 보존을 실제 DB에서 추가 검증했다.

## 무료 등급과 검증 비용

사용자가 무료 등급이라고 알려준 키로 검증했다. 결제 연결이나 유료 전환을 실행하지 않았다.
API 응답만으로 프로젝트의 최종 청구액을 확인할 수 없으므로 **실제 청구액 0달러라고 단정하지 않는다.**

검증 총 상한 US$1을 운영 예산과 분리했다. `tooling/validation-budget.ts`는 각 호출 전 파일에 보수적 비용을 예약하고,
실패/재시작에도 예약을 돌려주지 않는다. 단가 기반 예상치의 10배 또는 최소 1센트를 잡는다.
최종 누적 예약은 **US$0.59631404 / 24회 시도**이며 실제 청구액이 아니다. 여기에는 구형 모델의 404, 429, 형식 실패도 포함한다.
무료 할당량에서도 429가 날 수 있고, 무료 여부와 관계없이 앱의 운영 guard는 별도이다. 운영 `AI_DAILY_BUDGET`은 0이므로 상시 운영 채팅은 아직 차단된다.

Gemini 2.5 Flash-Lite는 메타데이터 조회에 성공했지만 생성 요청에 “신규 사용자 이용 불가” 404를 반환했다.
응답에서 안내한 3.5 Flash-Lite로 변경했다. 새 키로 실제 생성 성공을 확인했다.
현재 등록한 표준 단가는 입력 $0.30/백만 토큰, 출력 $2.50/백만 토큰이며 추론 토큰도 출력 비용에 포함한다.
[Google 가격표](https://ai.google.dev/gemini-api/docs/pricing), [모델 문서](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite), [안전 응답 규격](https://ai.google.dev/api/generate-content).
