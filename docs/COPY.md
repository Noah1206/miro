# MIRO Copy Guide

> 문장은 UI 의 일부다. 같은 상황은 같은 말로, 같은 톤으로.
> 코드에서는 `apps/web/lib/copy.ts` 를 쓴다. 페이지 안에 새 오류 문장을 직접 쓰지 않는다.

## 1. 목소리
- **조용하고 사람 같은 말.** 시스템이 말하지 않고, 화면 뒤의 사람이 말한다.
- 종결은 **"~해요"** 로 통일한다 (알림·오류·안내·CTA 보조 문장). 법적 고지(약관)만 "~합니다".
- 캐릭터의 말은 캐릭터의 말투를 따른다. UI 문장과 섞이지 않는다.
- 숫자를 말하지 않는다: 호감도·신뢰·점수·토큰·모델명·Provider 이름을 사용자 문장에 넣지 않는다.

## 2. 이름
| 개념 | 사용자에게 | 코드에서 |
|---|---|---|
| Roleplay session | 인연 (목록) / 역할극 (행위) | session |
| World state | 세계, 장면 | world, scene |
| Relationship | 관계 (문장으로) | relationship (수치) |
| Reality contact | 먼저 온 연락 | reality contact |
| Event | 일어나는 일 / 사건 | event |
| Usage window | 시간 (남은 시간) | usage window |

## 3. CTA
권장: 세계로 들어가기 · 이어서 보기 · 역할극 시작하기 · 다시 만나기 · 저장하고 시작하기
지양: 채팅 시작 · AI와 대화하기 · Start Chat · 확인 · OK

## 3.1 로그인 — 가입과 로그인을 나누지 않는다
- 버튼: `{제공자}로 계속하기` (Google / 카카오). "가입" 이라는 말을 쓰지 않는다 — 처음이면 만들어진다.
- 아래 밑줄 문장 `계정이 없으신가요?` 는 안내를 펼친다: "따로 가입하지 않아도 돼요. 위 버튼으로 계속하면 처음일 때 MIRO 계정이 만들어져요."
- 실패: `잠시 연결이 끊겼어요. 다시 이어볼까요?` · 취소: `로그인을 취소했어요. 준비되면 다시 시도해 주세요.` · 삭제된 계정: `삭제된 계정이에요. 같은 계정으로는 다시 들어올 수 없어요.`

## 3.2 약관 동의 — 실제로 눌러야 열린다
- 항목은 체크 표시 + 이름만. 설명 문장을 늘어놓지 않는다 (전문은 오른쪽 화살표로 연다).
- 꺼진 항목은 옅은 회색, 켜지면 흰색. "필수/선택" 같은 딱지를 붙이지 않는다 — 전부 필수다.
- CTA 는 위아래 두 줄: 위 `동의하고 가입하기` (전부 체크되면 `다음으로 진행하기`), 아래 `모두 동의하고 가입하기`.

## 4. 오류 — 무엇이 안 됐는지 + 다음 행동. 코드나 원인 설명은 넣지 않는다.
```
잠시 연결이 끊겼어요. 다시 이어볼까요?        ← 네트워크·Provider
이번 시간을 모두 썼어요. 18:20에 다시 열려요.  ← 사용량 (Free 는 Pro 안내를 덧붙인다)
지금은 저장하지 못했어요. 한 번 더 눌러 주세요.  ← 상태 충돌
```
개발 환경에서만 `observe()` 로 원인을 남긴다. 사용자 문장에는 넣지 않는다.

## 5. 상태·안내
- 진행 중: "{이름}이(가) 답을 고르고 있다" · "장면을 이어가는 중" (스피너 대신 문장)
- 빈 상태: 감정 맥락 → 다음 행동. "아직 이어진 인연이 없어요. / 누군가의 세계에 들어가 보세요."
- Provider 미구성: `⚠` + 사실 그대로. 숨기지 않는다.
- 성공: 짧게, 관계색은 관계 변화에만. "이제 먼저 연락이 올 수 있어요."

## 6. 접근성 문장 규칙
- 아이콘만 있는 버튼·링크는 `aria-label` 로 동사구를 준다: "전송", "뒤로", "닫기".
- placeholder 는 레이블이 아니다. 보이는 레이블이 없으면 `aria-label` 을 준다.
- 링크 이름은 목적지를 말한다: "구독 상태 보기" (○) / "여기" (✕).
- 영어 고유명사는 `lang="en"` 으로 감싼다: <span lang="en">Live Scene</span>.
- 제목은 화면마다 하나의 h1, 섹션은 h2 → h3 순서. 눈에 보이는 작은 레이블(t-micro)도 섹션 제목이면 h2 다.
