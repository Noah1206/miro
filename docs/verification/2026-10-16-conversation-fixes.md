# 허구 회상·반복·문자 재검토 수정 확인

## 적용 범위

캐릭터챗의 일반·자율성 경로와 문자 생성에 적용한다. 사용자 문장을 근거로 한 사실 주장과 조건·권유·캐릭터의 감상을 구분하며, 사용자 사실의 원문 출처·정확 인용·권한 범위를 검사한다. 거절된 초안은 표시하지 않고 기존 요청 예산 안에서 제한된 횟수로 다시 쓴다.

최근 자기 응답과 상당 부분 겹치는 문장, 바로 반복한 질문, 잦은 “기억해 둘게”, 반복 동작은 다시 작성한다. 짧은 인사와 고유 말투, 다른 화자의 대사, 사용자가 명시적으로 요청한 반복은 구분한다.

문자에서 defer와 시스템 기본 wait는 읽은 질문의 영구 종료 근거가 아니다(같은 날 사용자 결정으로 캐릭터가 근거를 들어 고른 wait는 읽씹으로 끝낸다 — [운영 확인 보고서](2026-10-16-production-conversation-check.md)). 질문을 큐에 유지하고 간격을 두고 재검토한다. 분명한 대화 종료·답장 불필요 요청에만 원문을 인용한 종료 근거를 남긴다. 새 unread 항목이 기존 read 질문을 밀어내지 않게 처리하며, 모델 오류는 읽음 상태를 잃지 않는다. 미열람 판단의 캐시는 같은 날·시간대 안에서만 유지한다. 시간이 바뀌었다는 이유로 강제로 읽거나 발송하지 않는다.

기존에 left로 종료된 문자는 일괄 되살리지 않는다. 중단한 데모와 두 장기 관찰 자동화도 재개하지 않는다.
