# 메시지 열람 선택 실제 모델 검증

2026-10-14 · 운영 모델 Claude Sonnet 5.5 · `messenger-attention:v2`

운영 환경의 모델 설정·키를 사용하되, 모든 대화와 변경은 별도의 로컬 테스트 DB에서 실행했다. 실제 사용자 원문과 기기 알림은 사용하지 않았다. 운영 코드와 같은 receiveMessenger → runMessengerInbox → chooseAttention → DB 확정 경로를 통과했다.

초기 24건 중 4건에서 구만석의 ‘폰을 안 켠다’를 ‘잘 안 켜지만 이 연락은 예외’로 완화해 열람했다. 읽기 행동으로 기기를 켜거나 작성 설정의 통신 제약을 바꿀 수 없으며, 예외에는 명시 설정 또는 이미 관측한 접근 복구 근거가 필요하다고 판단 지시를 보완했다.

수정 후 12상황 × 2회 = 24건, 감정만 바꾼 추가 2상황 × 2회 = 4건을 검증했다. 총 28건 모두 사전에 정한 허용 선택 집합 안의 선택을 했고, 미열람 본문은 모델 입력에 포함되지 않았다. 모두 운영 주 모델에서 성공했고 예비/Mock 대체는 없었다.

- 다정한 인물은 가까운 상대의 연락을 읽었다.
- 같은 신중한 인물도 친밀한 상대는 읽고, 낯선 상대는 보류했다.
- 신중한 인물의 갈등·상처 상황은 미열람 유지로 선택했다.
- 친밀도와 인물 설정을 그대로 두고 스트레스·부정 감정만 높이면, 즉시 읽기에서 보류로 바뀌었다.
- 서이안과 차도겸은 각자의 관심·보호 동기로 열람을 선택할 수 있었다. 갈등이라는 이유만으로 모든 인물이 같은 행동을 하지 않았다.
- 구만석의 기기 접근 제약이 있는 4건은 모두 보류 또는 미열람 유지였다.

원문 설정에서 검증 가능한 명시 규칙을 고정한 준비된 개정판을 사용했다. 설정 컴파일러의 품질 자체를 평가한 결과는 아니다. 이는 제한된 대표 상황의 결과이며 전체 캐릭터·장기 관계의 무오류를 입증하지 않는다.

호출은 초기·재검증·추가 비교를 합해 52회, 실제 보고 원가 약 $0.534, 보수적 누적 예약 약 $2.305였다. 같은 영속 원장에서 총 $3 이하를 강제했다. 별도로 타입 검사, 번역 누락 0건, 기록된 응답을 사용한 관련 검사 82개가 통과했다. 전체 검사에서 남는 기존 31개 실패는 앞선 변경 전 기준선에서도 동일하게 확인됐다.

세부 선택과 이유, 모델별 호출 기록은 같은 이름의 JSON 파일에 있다. 비밀값과 실제 사용자 대화는 포함하지 않는다.
