## 공통 방향 (10/15 사용자 결정)

- 그림체: **반실사 웹툰풍**(한국 로판·BL 웹툰 표지 같은 매끈한 반실사 일러스트).
- 참고: 위프 캐릭터 스크린샷을 **레퍼런스 이미지**로 쓴다(사용자가 직접 제공). 특정 캐릭터와 닮아 보이지 않도록 얼굴·머리·의상은 작품 설정대로 새로 만든다 — 그림체·조명·구도만 참고.
- 경쟁 서비스·기존 작품의 표지나 캐릭터 이미지를 그대로 가져오거나 합성하지 않는다.
- 피부: 모든 인물을 레퍼런스처럼 아주 하얀 도자기 피부로(10/15 사용자 결정).
- 모든 인물은 성인으로 보이게(학생 느낌의 체형·교복풍 금지 — 1번 사관학교 제복도 군사 아카데미 정복으로).
- 노출·선정적 포즈 없음. 5번은 오메가버스지만 생리 반응·성적 암시 연출 금지.
