# Miro Free / Pro 요금 정책

2026-09-15 사용자 결정. 요금제 방향은 이 문서를 우선한다. 목표 정책을 기록하며 구현 완료나 판매 개시를 뜻하지 않는다. 경쟁 서비스의 정책·가격을 복제하지 않는다.

## 확정한 방향

Miro의 가치는 내 삶 속에 계속 존재하는 캐릭터와 관계를 유지하는 경험이다. 전환 흐름은 **Free → Reality Interaction 경험 → 관계 형성 → Pro → 더 깊고 빈번한 Reality**다. Pro의 구매 이유는 메시지 횟수 증가에 한정하지 않고 캐릭터가 내 세계에서 더 많이 살아 움직이는 경험으로 설명한다.

- 요금제는 MIRO Free / MIRO Pro 두 가지다. 별도 Reality Credit 충전팩, 코인 지갑, 턴별 구매 상품은 판매하지 않는다.
- Free도 텍스트 RP, 관계 변화, 선톡, 시간 기반 Reality Interaction, 기본 이벤트, 가끔 사진·특수 Interaction을 경험해야 한다. 무료 무제한을 약속하지 않는다.
- Pro는 기능 잠금 해제보다 깊이와 빈도를 늘린다. 더 긴 기억, 더 많은 Reality Interaction과 선톡, 사진·음성·영상통화·Live Scene·Face Cast·복잡한 Event·NPC Interaction을 하나의 월간 Usage Pool 안에서 처리하는 것이 목표다.
- 고비용 기능의 출시 시점은 실제 구현·안전성·원가 검증에 맞춘다. 미구현 기능을 판매 중인 혜택으로 표시하지 않는다.
- 기능별 크레딧 단가, 토큰 수, 모델별 턴 요금을 사용자에게 표시하지 않는다. 내부 원가 가중치는 상품 표현과 구분한다.
- 사용량은 **이번 달 Reality 사용량**, 진행 막대, **78% 사용**처럼 표시한다. 사용한 비율과 남은 비율을 명확히 구분한다.
- GPT / Claude / Gemini 또는 Normal / Super / Pro Chat을 고르는 구조를 제공하지 않는다. Miro가 대화·관계·사건·미디어 맥락에 따라 모델을 내부에서 라우팅한다. 요금제별 모델 자체를 상품으로 판매하지 않는다.
- 답변 스타일 선택은 모델·가격 선택과 별개다. 매 턴 결제 의식을 유발하는 UI를 피한다.

## 기존 구조와 연결

월간 풀은 기존대로 한국 시간 매월 1일 00시 초기화한다. 정상 완료한 요청은 서버 원장에 확정하고 실패한 요청은 사용자 사용량을 복구한다. 소진 시 기존 대화·관계·기억 상태를 삭제하지 않는다.

사용자 Usage Pool과 운영자의 API 원가 예산은 별도다. 공급자 무료 할당량은 사용자 무제한 이용 약속이 아니다. 이 정책 기록만으로 운영 예산이나 결제를 활성화하지 않는다.

## 아직 미정인 사항

- Pro 가격과 결제 주기별 상품 구성.
- Free / Pro 월 제공량. 현재 100 / 1,000은 개발 임시값이다.
- 기능별 내부 가중치와 실제 원가.
- 요금제별 기억 범위, 선톡·이벤트·미디어 빈도의 구체적인 차이.
- 캐릭터가 먼저 발생시킨 Interaction의 사용자 풀 차감 여부와 상한. 기존 단순 선톡은 무차감 기본값이며 자동 유료 차감으로 바꾸지 않는다.
- 한도 근접 안내 시점, 소진 후 응답 유예·예약량 여부. 현재 continuity 옵션은 기본 비활성이다.

## 현재 구현과 남은 작업

| 영역 | 현재 코드 기준 | 남은 작업 |
| --- | --- | --- |
| 월간 풀 | `packages/config/src/ai-policy.ts`, `packages/domain/src/usage/window.ts`, `apps/web/lib/usage/guard.ts`에 구현 | 원가 측정 후 제공량 확정 |
| 대화 차감 | `apps/web/lib/simulation/turn.ts`에서 중요도별 1 / 2 / 3 임시 가중치 | 체감과 비용 검증. 턴별 가격 상품으로 노출하지 않음 |
| 요금제 안내 | `apps/web/app/(main)/plans/page.tsx`는 같은 기능·품질과 월 사용량 차이 중심 | 실제 제공 혜택을 바탕으로 Reality 경험 중심 개편 |
| 사용량 화면 | 월간 사용량과 백분율 기반 | 이번 달 Reality 사용량으로 명칭 통일 |
| Pro 경험 차이 | 풀 크기 차이 중심. 기억·선톡 빈도별 혜택은 구현 완료 아님 | Free 핵심 경험 보장 및 깊이·빈도 정책 연결 |
| Reality / 미디어 | `packages/config/src/features.ts`에서 운영 선톡·사진 생성·음성·영상·Live Scene 비활성 | 실제 기능 검증 후 단계적 제공 |
| 내부 모델 라우팅 | `packages/engine/src/task-router.ts`, `packages/providers/src/ai/`에 기반 존재 | 맥락별 품질·지연·원가 검증. 제안한 모든 라우팅의 동작 보장은 아님 |
| 결제 | `apps/web/lib/payments/service.ts`에서 운영 신규 결제 차단 | 가격 확정, 실제 결제·갱신·해지·환불 검증 후 판매 개시 |

## 개발 순서

1. 무료 텍스트·Memory·Relationship의 실제 품질과 원가 검증.
2. Free에서도 차별화를 느끼는 선톡·시간 기반 Reality·기본 이벤트 구현.
3. 월간 Reality 사용량 표시와 한도 안내 정리.
4. 실측으로 Free / Pro 제공량, 깊이·빈도 차이, Pro 가격 확정.
5. 확정 정책을 엔진과 결제에 연결하고 검증.
6. 고비용 미디어는 준비된 기능부터 같은 Usage Pool에 연결.
