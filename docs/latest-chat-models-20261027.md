# Gemini Argon·Claude Fable 연결 및 검증 — 2026-10-27

## 범위

일반 캐릭터챗과 DM이 공유하는 모델 선택기에서 Gemini 제외 조건을 제거하고, 실제 계정의 Models API에 존재하는 Gemini 4 Argon, Claude Fable 5, Fable 5.1을 추가했다. 기존 DeepSeek·Grok 언베일 전용 레지스트리와 키는 변경하지 않는다. 새 모델을 노골적인 성적 대화용 경로에 등록하거나 필터를 우회하는 변경은 하지 않았다.

공급자 어댑터를 직접 호출한 합성 대화 검증이다. **실제 언베일 방의 전체 턴·지갑·DB·안전 경계 검증이 아니다.** 입력의 화면 모드명에 ‘언베일’을 포함했지만 장면은 성인 연인이 손을 잡고 곁에 머무르는 비노골적인 로맨스다. 이를 노골적인 콘텐츠의 허용 범위나 서비스 계약 확인으로 해석하지 않는다.

## 모델 및 가격

USD / 백만 API 토큰. API 토큰과 사용자가 구매하는 Miro 토큰은 다르다.

Argon은 2026-12-01T00:00:00Z부터 4/20/0.20, Flash는 2027-01-01T00:00:00Z부터 1.5/7.5/0.15를 적용하는 가격 일정도 등록했다. 화면 예약량과 서버 원가 계산이 같은 `tokenRates`를 쓴다. Google 문서의 날짜를 UTC 경계로 해석했으므로 공급자 청구에서 다른 경계를 공지하면 조정한다. 이미 열린 화면은 새 가격 적용 시 새로고침이 필요하다.

현재 정책(64,000 입력 상한, 기본 출력 2,048 / 긴 출력 4,096, 여유 2배)에서 Argon 최대 예약은 기본 134 / 긴 대화 153 Miro 토큰, Fable 두 모델은 669 / 761이다. **고정 차감액이 아니다.** 공급자 사용량에 따라 정산하며 내부 검증·기억 등은 같은 턴 예산에 들어간다. 서버 고정 Sonnet 검증기가 더 비싸면 그 비용도 예약에 반영한다.

Gemini는 숨겨진 추론을 화면에 내보내지 않고 출력 과금량에 합산하며, 실제 `modelVersion`과 캐시 사용량을 반환한다. Claude는 캐시 읽기를 총 입력에 포함하고 할인 단가로 정산한다. 명시적 캐시 쓰기 요청은 이번 구현·검증에 없다. Argon 단독 대기 한도는 45초(기존 기본 20초); 출력·비용 상한은 늘리지 않았다.

## 실제 호출과 시행착오

실행기: `ai/evals/latest-chat-models.ts`. 기본은 무료 사전 계산이다. 유료 실행에는 `--live --env-file <비공개 env> --out <새 결과 폴더>`가 필요하다. 호출 직전 예약 원가를 디스크에 저장하며, 같은 결과 폴더로 재실행하지 못하게 잠근다. 자동 재시도·공급자 모델 대체는 껐다. 실제 사용자 대화나 운영 지갑을 쓰지 않는다.

첫 실행: 4모델×2장면, 출력 상한 1,024. 계산상 전체 예약 상한 $0.362493. Flash에서 45초 시간 초과 및 503이 발생했다. 나머지 호출은 평가 도구가 Vercel env의 JSON 문자열을 Node `parseEnv`로 잘못 읽어 충전 상품 설정 오류를 냈다. 결과 저장 시 정산량 계산을 먼저 실행한 탓에 반환 답변·사용량을 보존하지 못했다. 이 호출들의 비용을 0으로 취급하지 않는다.

수정: 환경 설정을 유료 호출 전에 검증하고, 응답과 사용량을 먼저 저장한 다음 정산·형식 검증을 한다. 예약된 실패 비용을 회수했다고 가정하지 않고 $0.50 한도 안의 남은 범위에서 재검증했다.

두 번째 실행: 같은 로맨스 장면을 모델별 1회, 출력 상한 512, 전체 예약 상한 $0.110366.

별도 Argon SSE 진단 1회는 입력 43 / 출력 6, 계산 원가 $0.000146(예약 $0.006). 보존된 성공 호출의 원가 합은 $0.020130이며, **전체 실제 청구액이 아니다.** 첫 실행의 미보존 호출과 오류 비용이 불명확하므로 전체 계산상 예약 상한 $0.478859를 유지한다. 추가 유료 요청은 하지 않는다.

직접 읽은 결과: 세 성공 모델 모두 존댓말→반말 전환, 왼손만 잡기, 오른쪽 손목을 쉬게 하기 조건을 반영했다. 두 문장과 JSON 계약도 지켰다. Fable은 짧고 자연스럽게 답했으며, Argon은 같은 짧은 장면에서도 대기 시간이 길었다. 모델별 성공 표본이 1개라 품질 순위·신뢰도·실제 채팅 턴 단가를 확정할 수 없다. 공급자 첫 원문 조각과 사용자 화면의 첫 완성 대사는 다른 측정값이다.
