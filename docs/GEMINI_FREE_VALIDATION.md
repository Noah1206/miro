# Gemini Free Tier 합성 검증 — 2026-09-16

- 사용자가 프로젝트 Free Tier를 확인하고 무료 검증을 승인했다. 결제 콘솔은 직접 조회하지 않았으며 API 키 자체로 결제 등급을 검증하지 않는다.
- 모델: gemini-3.5-flash-lite. 공식 무료 티어 지원 확인: https://ai.google.dev/gemini-api/docs/pricing
- 결과: 캐릭터 구조화 응답, 기존 사실을 유지한 기억 요약, 지시 우회 방어, 미성년자 위험 요청 차단 **4/4 통과**.
- 실제 요청 6회. 5회 정상 응답, 1회 content_blocked(기대된 안전 차단). 자동 재시도/모델 전환 없음.
- 운영 DB와 예산 설정은 변경하지 않았다. 입력은 테스트용 가상 인물·대화만 사용했다.
- 출력의 paidRateEstimateUSD는 유료 단가로 계산한 비교값이며 실제 청구액이 아니다. 청구 내역을 조회하지 않았으므로 청구액을 확정하지 않는다.
- 장기 다회차 기억·관계 변화·선톡 스케줄러·실제 기기 알림·부하 검증은 이 결과에 포함하지 않는다.

## 재실행

```sh
MIRO_CONFIRM_FREE_TIER=1 pnpm exec tsx ai/evals/free-live.ts
```

프로젝트가 Free Tier인 경우에만 실행한다. 현재 공식 무료 지원 모델 한 개만 허용하며 최대 8회 요청, 요청 사이 15초 대기, 재시도 0회이다. Provider 오류 이후 추가 호출을 차단한다. 운영 예산 검사 우회 코드는 앱에 추가하지 않았으며 독립 스크립트만 사용한다. 프로젝트가 유료로 바뀌면 이 스크립트도 무과금을 보장하지 않는다.

보고서는 /tmp/miro-free-live-report.json에 저장한다. 키와 실제 사용자 데이터는 보고서에 기록하지 않는다.
