# 베이비챗·크랙 제작 UX 조사 (2026-10-19)

출처: 두 서비스에 로그인한 실제 제작 화면(2026-10-19 확인) + 공식 도움말 + 나무위키·커뮤니티(체감 평가는 "후기"로 표시).

## 3. 유저가 체감하는 편의 기준 (제작자 관점)

1. **빈칸을 AI가 채워 준다** — 두 곳 모두 거의 모든 긴 입력란에 "자동 생성/자동 완성"이 붙어 있다. 크랙은 프로필까지 랜덤 생성. 첫 캐릭터 완성까지의 벽이 "글을 못 써도 된다"로 내려감.
2. **쓰면서 바로 대화해 본다** — 베이비챗은 제작 화면 우측에 항상 테스트 채팅(10회), 크랙은 프롬프트 단계부터 미리보기. 저장·등록 없이 품질을 확인.
3. **한도가 항상 보인다** — 모든 입력란에 `0 / 1,000` 식 카운터. 제작자 커뮤니티가 글자수 한도로 서비스를 비교할 만큼 핵심 지표.
4. **인트로를 채팅처럼 쓴다(크랙)** — 숨은 배경·캐릭터 말풍선·사용자 말풍선·이미지를 실제 채팅 UI에서 조립. 베이비챗은 "첫 상황 + 첫 대사" 두 칸.
5. **시작 설정 여러 개** — 같은 캐릭터로 "학창시절/대학생/결혼 후"처럼 분기. 베이비챗도 2026-01에 추가.
6. **이미지가 자동으로 뜬다** — 상황별 이미지에 설명만 달면 AI가 골라 출력. 크랙 스토리는 파일명 규칙(`에리_기쁨.jpg`)으로 1,000장을 한 번에 분류.
7. **유저에게만 보이는 안내** — 플레이 가이드(AI 비반영) + 추천 답변 3개. 첫 턴에 뭘 쳐야 할지 모르는 이탈을 줄임.
8. **권장 모델·출력량을 제작자가 못 박는다** — 유저 방에서 "제작자 권장 설정 / 직접 설정" 토글로 보임.
9. **재사용** — 로어북 불러오기, 단축어 "내 단축어"에서 가져오기, 스탯 다른 시작설정에 복제.
10. **등록 전 안전 장치** — 성인/미성년 구분은 한번 정하면 변경 불가(두 곳 공통), 이미지 AI 사전 검열(크랙).

## 5. "성능" 우위로 유저가 꼽는 것 (후기 기준, 수치 비교 자료 없음)

- 베이비챗: 검열 낮음(최대 장점), 모델 가격이 단일 재화(프로챗)로 직관적, 로어북 100개·유저노트 무제한 등 "칸이 넓다", 한국 라노벨 문체. 약점은 장기기억(메모리+ 끊김, 요약이 사건 놓침)과 운영 신뢰.
- 크랙: 모델 14종·광고 없음·크래커 가성비(Opus 턴당 92~102원), 유저풀 최대, 스토리 빌더(스탯·엔딩·단축어)로 "게임"이 됨. 약점은 검열 오탐, 유저노트·프로필 한도 작음, 무료 크래커 효율 하락.
- 속도: 둘 다 공식 수치 없음. 커뮤니티는 모델·출력 길이·스트리밍 여부가 체감을 좌우한다고 봄. 크랙은 답이 길어 티키타카가 어렵다는 불만, 제타는 짧은 대화에 강하다는 평.
- 기억: 크랙이 요약 시스템 v3 + 장기/단기/관계도/목표 구조로 더 체계적이라는 평, 베이비챗은 기억력이 "유일한 아쉬움"으로 반복 언급.

## 6. 미로에 바로 대입할 때 눈에 띄는 차이

- 미로 제작기엔 자동 생성 버튼·실시간 테스트 채팅·글자수 카운터·플레이 가이드·추천 답변·시작 설정 복수가 없거나 약함.
- 미로의 강점(자율성·먼저 연락·현실 시계·관계 성격표·오리지널 스토리 구조)은 두 서비스 제작기 어디에도 노출되지 않는 항목이라, 제작기에서 "이 캐릭터가 혼자 하는 일"을 설정하게 하면 차별점이 됨.
- 크랙 스토리의 스탯/엔딩/단축어는 미로 오리지널 스토리(목표·기한·사건 5·결말 3갈래)와 구조가 겹침. 제작자에게 열 때 참고.

조사 중 크랙 계정에 빈 draft(캐릭터 1, 스토리 1)가 "내 작품 → 미등록"에 남았음. 베이비챗은 저장 안 함.
