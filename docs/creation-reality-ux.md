# 캐릭터 만들기와 리얼리티 연결

2026-09-23. 로컬 구현. 운영 배포나 DB 마이그레이션은 수행하지 않음.

## 저장 정책

- 새 캐릭터는 먼저 연락하기가 켜져 있으면 reality, 꺼져 있으면 chat으로 생성한다.
- 기존 chat 캐릭터는 일반 편집 저장으로 reality가 되지 않는다. 편집 UI에서는 실제 사용 가능한 상태인 꺼짐으로 표시하되, 토글을 건드리지 않으면 기존 contact profile 값을 보존한다.
- 기존 chat에서 명시적으로 먼저 연락하기를 켜고 저장하면 reality로 전환한다. 서버는 소유자를 검사하고 DB의 현재 유형을 사용한다. 임의 experienceType 폼 필드는 무시한다.
- reality에서 연락을 꺼도 사진/통화 등 기존 자격을 없애는 chat 강등은 하지 않는다. contact.enabled=false 및 세션의 pendingRealityIntent 취소로 자동 연락만 중지한다.
- 기능 플래그, 사용량 제한, 실제 수신자의 통화 허용 및 방해 금지 정책은 계속 적용된다. 사진/통화의 운영 플래그는 이번 작업에서 열지 않는다.
- 연락 OFF는 스케줄 후보와 평가 초기 단계에서 차단한다. 메시지 저장 직전에 contact profile을 재검사하며, 수신 통화 생성도 다시 확인한다. 이미 대기 중인 푸시는 발송 직전 OFF를 확인하고 취소한다.
- 편집 시 잠금 순서는 캐릭터 → 세션(연락 OFF일 때) → 연락 프로필. 평가 저장은 세션 → 연락 프로필 순서여서 순환 대기를 피한다.

## 화면

- 프로필·세계관·외형·관계·일상·연락·인트로 구조 유지. 게시 버튼 옆에는 미입력 필드 또는 공개 여부를 표시한다.
- 관계: 낯선 사이/동료/친구/썸/연인 추천값과 요약. 나머지 단계와 6개 세부값은 세부 편집에서 제공한다. 직접 편집한 값을 다른 프리셋으로 바꿀 때 유지/추천값 적용/취소를 선택한다.
- Stepped는 가까운 라벨을 표시하되, 실제 값은 사용자가 선택하기 전까지 보존한다. 접힌 필드도 제출된다.
- 일상·연락: 스위치, 3단계 빈도, 선호 채널, 정적 행동 예시. 채널은 반드시 해당 방식으로만 보내라는 금지 설정이 아니라 기존 엔진의 선호 값이다.
- 지원하지 않는 채널은 새 선택지로 열지 않는다. 기존 선택은 준비 중으로 보존한다. 세부 선호 값은 기존 편집 기능으로 유지하며 런타임 기능 플래그가 우선한다.
- 인트로 실제 대화와 공개 상황 예시를 분리. 미리보기에서 소개 페이지/첫 대화를 전환한다. 첫 대화는 저장할 인트로 메시지이며 AI 생성 데모가 아니다.
- 사용자 데이터 제출 없이 localhost UI를 검증한다. 저장/실행 검증은 tooling/test-database.ts가 허용한 로컬 miro_test에서만 수행한다.

## 검증 범위

생성/편집 서버 액션, 기존 유형 보존/명시적 활성화, OFF 시 pending 취소·스케줄 제외·inline 차단, 통화 설정/방해 금지, 대기 푸시 취소, 소유자 권한, 인트로 회귀 테스트. 실외 알림/유료 미디어 전송과 운영 배포는 별도 검증 대상이다.

## 2026-09-24 UI 수정

제작자가 캐릭터의 연락 수단까지 지시하지 않도록 선호 연락 방식, 행동 예시와 관련 안내를 제거했다. 세부 편집의 사진/음성/통화 선호 조절도 제거했다. 기존 캐릭터 편집으로 값이 초기화되지 않도록 해당 필드는 hidden 입력으로 보존하며, 엔진의 판단 방식은 이번 UI 수정에서 변경하지 않는다. 먼저 연락하기·연락 빈도·발신자 표시·연락 주도성은 유지한다.

### 관계 선택 디자인 후속 수정

관계 프리셋을 기존 엔진의 11가지 stage로 확장하고, 낮은 높이(32px)의 둥근 칩을 사용한다. 관계의 세부 편집 열기 버튼은 제거하고 6개 초기 감정 항목을 항상 표시한다. 각 항목은 5단계이며 기존 0–100 값 저장 형식을 유지한다. 신뢰와 거리 / 호감과 유대 / 상대를 향한 감정의 세 그룹만 surface-1 배경으로 구분하고, 그룹 내부에는 추가 카드나 구분선을 두지 않는다. 직접 수정한 값을 프리셋이 덮어쓰지 않도록 변경 확인은 유지한다. 설정집 연결 기능은 추가하지 않았다.

둥근 칩은 시작 관계의 11가지 선택에만 적용한다. 아래 6개 감정 항목은 기존 사각형 단계 버튼을 사용한다.

관계의 각 감정 항목은 최종 3개 선택지로 축소했다. 기존 저장값은 그대로 보존하고, 사용자가 누른 경우에만 선택한 단계값으로 변경한다.

최종 선택지 수는 항목별 의미에 맞춰 가변으로 정리했다: 신뢰 4, 호감 4, 정서적 거리 3, 애착 3, 보호 성향 3, 질투 2(없음/있음). 기존 수치는 직접 선택하기 전까지 보존한다.
