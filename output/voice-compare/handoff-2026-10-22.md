# 미로 음성 작업 인수인계 (2026-10-22)

## 프로젝트
- 미로: 여성향 BL 중심 1:1 AI 캐릭터챗 앱. 몰입 모드에서 캐릭터 대사를 TTS로 읽어 줌. 성인 모드 '언베일' 있음.
- 원하는 음성: 귀에 대고 말하는 ASMR·오디오드라마식 **남자 캐릭터 연기 음성** (속삭임·숨·웃음·머뭇거림·감정, 언베일용 성인 장면까지). 깨끗한 낭독은 정반대.

## 현재 구조
- 학습: Modal T4 GPU에서 GPT-SoVITS v2 파인튜닝 (목소리당 4~10분, $0.1~0.3)
- 합성: 맥북 gsv_server(8787) + ngrok 고정 주소 → 운영 앱
- 데이터 정제 파이프라인: Demucs(음악 있을 때만), -23 LUFS, slicer, PANNs로 효과음 제거·속삭임/숨 태깅, faster-whisper 받아쓰기, 화자 필터
- 운영 목소리: Zeroth 템플릿 2~4(CC BY 4.0) + AI Hub 71349 여자 성우 12명(낭독 600문장씩). 유튜브 출처 목소리는 권리 문제로 전부 삭제함.

## 문제
모든 결과가 "AI가 대본 읽는 것 같다, 억양이 부자연스럽다, 감정이 없다".

- Qwen 파인튜닝은 10/21 시도했으나 1시간 제한으로 결과물 없음.

- 도구: tooling/voice/prosody_compare.py

## 결론과 남은 선택지
- 설정·참조 조정으로는 해결 안 됨.
- 원인: (1) 데이터가 성우 낭독 (2) 모델의 한국어 구어 억양 학습 부족. 참고: 토스는 오픈소스 구조지만 대량의 실제 한국어 대화 데이터로 모델 자체를 재학습함.
- 예전 유튜브 ASMR 속삭임 데이터로 만든 목소리는 "훨씬 사람 같다"는 평 → 데이터가 핵심이라는 증거.
- 선택지
  - A. Chatterbox Multilingual 비교 (저비용, 기대 낮음)
  - B. 데이터 교체: 남자 ASMR 성우 직접 녹음(성인·AI 학습 서면 동의, 1~2시간, 감정·장면별 대본) 또는 AI Hub 자유대화 데이터로 바탕 모델 한국어 재학습 (권장)
  - C. 상용 서비스 귀로 확인: ElevenLabs v3, 타입캐스트, 수퍼톤 웹 데모

## 제약
- 성인·신음 학습은 성인 용도 서면 동의한 성우 녹음으로만.
- AI Hub 데이터는 해외 다운로드 차단, 상용 서비스 복제 시 이용 조건 확인 필요.
- 투자 일정 촉박 → 무작정 재학습 반복 금지, 원인 확인 우선.
