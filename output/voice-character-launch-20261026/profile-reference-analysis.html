설계 판단

  • 현재 기능으로 연결되는 메뉴만 배치. 보상/팔로워/구독 상품을 임의로 만들지 않음.
  • 기존 실제 잔액과 지갑 제공자를 유지. 유료 주문은 생성하지 않고 충전 시트 열기만 검증.
  • 그룹은 내 활동·앱 설정·고객지원으로 나눔. 위험한 계정 삭제는 하단 별도 링크로 보존.
  • 편집·충전·설정 접근·내역 주요 컨트롤 최소 터치 44px.
  • 큰 잔액과 통계는 줄바꿈, 긴 이름/이메일은 말줄임. 영문·일문·중문 번역 보완.
  • 사용자 실험으로 최적임이 증명된 디자인이라는 의미가 아니라 레퍼런스와 Miro 현재 목적에 맞춘 설계 판단.
