# Miro 음성 캐릭터챗 출시 상태

2026-10-26 최신 결정: **이번 출시는 음성을 제외하고 기존 리얼리티 인터랙션·문자·상황 이미지 중심으로 진행한다.** 아래 음성 계획과 구현은 후속 재개용으로 보존한다.

## 현재 음성 보류 상태

- `MIRO_FEATURE_CHARACTER_VOICE=0`이 기본값이다. 채팅방 음성 모드·잔여량·구매·말로 쓰기, 캐릭터 생성/편집의 음성 선택을 숨겼다.
- `/api/tts`는 기능 OFF일 때404를 반환한다. 초 체험 지급/구매와 워커 신규 합성도 차단한다. 기존 대기 작업의 취소·반환은 가능하다.
- 기존 목소리 선택 값·음성 잔액·저장 가중치·원본·학습 코드·정산 코드는 삭제하지 않는다. 실행 중이던 로컬 테스트 합성 워커는 종료했다.
- 리얼리티 문자·관계·기억 기능과 기존 이미지 경로는 변경하지 않는다. 로컬 앱에서 음성 메뉴 제거 및 문자 전송 저장을 확인했다.
- 보류 경로 포함 집중 테스트35개/전체 타입 검사 통과. 운영 배포·추가 유료 실행은 하지 않았다.
- 나중에 모델 검증을 완료한 뒤 명시적으로 기능 플래그를 켜서 재개한다. 오래된 방의 ON 기억만으로는 기능이 켜지지 않는다.

모든 앱 검사는 독립 로컬 테스트 DB와 로컬 가짜 공급자를 썼다. 재생한 소리는 0.2초 테스트 톤이며 새 모델 음성이 아니다. 이미지도 테스트 에셋이다. 새 유료 실행·결제·학습·서버 임대·운영 배포는 하지 않았다.

## 제품 동작

- 음성 모드를 켜도 자동 생성하지 않는다. 최신 캐릭터 대사 최대 3개 중 하나를 선택하고 차감 안내 후 듣는다. 서술·분위기·NPC 대사는 음성 요청에서 제외한다.
- `보통`: 최대 40자/10초, `길게`: 최대 80자/20초. 같은 모델·샘플링 품질이며 분량만 다르다. 길이 한도에 닿은 결과는 잘림 가능성이 있어 실패로 처리한다.
- 생성 전에 최대 초를 예약하고, 서버가 검사한 실제 WAV 길이를 1초 단위 올림해 확정한다. 남는 예약은 반환한다. 무음·잘못된 오디오·실패·불명확 응답은 분량을 반환한다.
- 캐시 재생은 추가 차감하지 않는다. 무료 재생 캐시가 중간에 만료되면 자동 유료 생성하지 않고 새 안내가 필요하다. 완료 캐시는 24시간이며 영구 무료 보관이 아니다.
- 대기 중 취소는 예약을 반환한다. 이미 공급자에 전송된 계산의 즉시 취소는 보장하지 않는다. 결과 불명확 시 신규 공급자 호출을 멈추며 자동 유료 재시도는 없다.
- 음성 초는 기존 가입 보상/월 채팅 사용량과 분리한다. 분량 구매는 실제 구매 충전금만 사용하고 UUID로 중복 구매를 막는다.
- 상황 에셋은 명시된 캐릭터·장소·일반/언베일 등급이 맞아야 재사용한다. 미분류 갤러리 전체를 상황에 맞는 에셋이라고 간주하지 않는다. 언베일 공급자가 없으면 일반 이미지로 대체하지 않는다.

## 실제 모델과 원가

최신 남성 13회 Full FT는 저장되어 있다. 독립 엔진 재로드·native export·새 비교 음성은 아직 완료되지 않았다. Modal Usage에서 workspace Paused와 누적 net usage $139.94, 동결된 한도 $163.07를 확인했다. 미결제 해결은 계정 소유자가 처리해야 한다. 학습부터 다시 시작할 상황이 아니다.

`output/voice-character-launch-20261026/MODEL_EVAL_REQUESTS.json`에는 보통/긴 분량 × 일반/속삭임/언베일 말투의 6개 검증 요청이 있다. 언베일 말투용 비노골적 대사만 준비되어 있으며 성인 발성 전체를 검증한 것은 아니다. 확정된 숨 이벤트 라벨도 0개다.

실측 원가는 로딩·유휴·실패까지 포함한 전체 청구액을 완성·내용 통과·음색 승인된 음성 분량으로 나눈다. 정상 출력이 0개이면 원가를 0원으로 표시하지 않는다. 아직 새 모델의 분당 실제 원가를 제시할 근거가 없다.

WAV 유효성·무음 검사는 대사 누락을 판별하는 ASR 검사가 아니다. 운영 워커의 출력별 전사 완주 검증은 아직 없으므로, 새 모델 검증 및 품질/환급 정책 확정 전에 음성 판매를 활성화하지 않는다.

## 운영 활성화 순서

1. 계정 복구 후 기존 승인 잔액 범위에서 13회 모델 검증·변환·비교만 한다. 새 학습은 하지 않는다.
2. 실제 원가·지연·실패율과 대사 완주/음색/연기를 확인하고 판매량을 정한다.
3. 새 DB 마이그레이션 `20261026094906_speech_credit_accounts.sql`을 기존 큐 마이그레이션 이후 적용한다. 이번에는 로컬에만 적용했다.
4. 웹·별도 워커의 모델/참조 버전과 요청별/사용자별/전역 지출 예약 값을 실제 측정치로 맞춘다. 앱 예약 상한만으로 GPU 유휴 청구가 중단되지는 않는다. 공급자 자체 상한도 필요하다.
5. 검증한 다음 `MIRO_FEATURE_CHARACTER_VOICE=1`, `MIRO_TTS_QUEUE_ENABLED=1`, `MIRO_SPEECH_CREDITS_ENABLED=1`, 실제 상품과 체험 정책을 설정한다. 기본 상품은 빈 배열이며 운영 판매는 비활성이다.
6. 에셋 메타데이터·정상/언베일 이미지 모델을 확인한 후 `MIRO_SCENE_IMAGES_ENABLED=1`을 설정한다. 운영 기본값은 꺼짐이다.
7. iPhone 홈 화면 앱/Android에서 실제 오디오 재생·취소·복귀·키보드를 확인한 뒤 소수 초대 사용자에게 연다.

새 백업 이전비 최대 $3/월 보관 $3.50 제안은 미승인 상태다. 이번 진행을 새 비용의 승인으로 해석하지 않는다. 기존 가중치·원본 녹음은 보존했다.

## 검증 증거

- 새 음성 초/큐/오디오/에셋/선택 재생 집중 테스트 32개 통과, 전체 타입 검사 통과, CPU HTTP 어댑터/원가 집계 Python 5개 통과.
- 기존 사용량 관련 넓은 검사 중 12개 실패는 수정 전 guard로도 동일하게 재현했다. 전체 테스트가 모두 통과했다고 주장하지 않는다.
- `output/voice-character-launch-20261026/`에 로그·모델 차단 상태·브라우저 기록·스크린샷을 보관했다.
