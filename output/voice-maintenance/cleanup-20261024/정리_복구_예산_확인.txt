Miro 음성 저장공간 정리 및 복구 확인 — 2026-10-24

삭제 완료
클라우드: 약 151.14 GB. 이전 Qwen 학습 결과, 과거 음성 비교 실험, VoxCPM·Qwen·F5·Chatterbox 등의 공개 모델 캐시, Drama 3 공개 모델 캐시를 정리했습니다.
맥: 약 1.47 GB. 이전 음성 비교 결과와 pip 다운로드 캐시를 정리했습니다. 디스크 여유는 약 9.3 GiB로 확인했습니다.
삭제 전후 원격 목록을 대조했고, 지정한 삭제 대상은 사라졌습니다. 공개 모델 캐시는 다음 사용 전에 다시 내려받아야 합니다.

보존
007번 등 권리 확보 원본 데이터, 운영 GPT-SoVITS 보이스 및 서버, 현재 학습 코드, 현재 실패 기록을 보존했습니다.
현재 1회 가중치와 5회 잔여 파일은 삭제 범위에 대한 답변을 받기 전까지 보존합니다. 이 보존 대상의 파일 크기·목록은 정리 전후 동일합니다.
운영 음성 서버의 상태 조회는 정상입니다. 클라우드에서 실행 중인 컨테이너는 없고, 이전 Qwen 실험 앱과 로컬 비교 서버들을 종료했습니다.

복구 확인
5회 저장본에는 핵심 가중치/옵티마이저 조각 8개 중 1개만 남았습니다. 나머지 모델 상태 파일 8개를 실제로 열어 확인했으며, 텐서는 빈 자리 표시자이고 실제 가중치 데이터는 없었습니다. 따라서 이 파일들을 합쳐도 완전한 5회 모델을 만들 수 없습니다.
실패한 컨테이너는 조회 시 존재하지 않으며, 공개 Volume/Container API에 사라진 조각의 복구·버전 이력 기능은 없습니다. Modal 내부에 별도 보존본이 있는지는 지원팀만 확인할 수 있습니다. 외부 문의는 보내지 않았습니다.
기존 1회 추론용 가중치는 온전하게 보존돼 있습니다. 이 파일에는 당시 옵티마이저 상태가 없으므로, 완전한 학습 상태 재개와는 구분해야 합니다.

예산 — 현재 청구 집계 기준, 향후 확정 청구 보장 아님
추가 총한도 44달러 중 현재 사용액 25.93달러, 남은 금액 18.07달러입니다.
동일한 8 H100 구성에서 측정한 평균 업데이트 시간은 약 83.91초입니다. 현재 보존된 1회 가중치에서 25회까지 24회를 학습하는 연산만 약 20.96~22.11달러로 추정됩니다.
실측한 초기 로드와 5회 단위 저장 파일 쓰기까지 더한 소계는 약 32.27~34.03달러입니다. 성공한 원격 저장, 완전한 학습 상태 재로드, 최종 가중치 내보내기, 비교 음성 생성 비용은 이 소계에도 포함되지 않았습니다.
따라서 남은 18.07달러로 기존과 같은 범위를 완료할 수 있다고 약속할 근거가 없습니다. 성공한 저장 시간 측정이 없어 정확한 총액 또는 최소 비용을 확정할 수는 없습니다.
새로운 GPU/CPU 클라우드 작업은 시작하지 않았고, 청구 조회 금액은 정리 전후 55.93달러로 동일했습니다. 저장공간을 삭제해도 이미 발생한 연산 사용료는 환불되지 않습니다.
